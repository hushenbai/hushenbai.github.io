# PDF下载功能说明

## 功能概述
在 `index.html` 页面的 `<div class="pdf-download"></div>` 区域添加了一个PDF下载模块，用户可以下载"良药 - 申白作品集"PDF文件。

## 防恶意下载保护措施

### 1. 频率限制
- **下载间隔限制**: 每次下载之间必须间隔60秒
- **每小时限制**: 每个用户每小时最多下载5次
- **每日清理**: 自动清理24小时前的下载记录

### 2. 本地存储追踪
- 使用 `localStorage` 记录用户的下载历史
- 防止用户通过清除浏览器数据绕过限制
- 自动清理过期记录，避免存储空间占用过多

### 3. 用户体验优化
- 实时显示下载状态和错误信息
- 显示当前下载次数和限制信息
- 按钮状态管理（禁用/启用）
- 多语言支持（中文/英文）

### 4. 技术实现
- **前端限制**: JavaScript实现的客户端限制
- **文件保护**: 添加时间戳防止缓存
- **错误处理**: 完善的错误捕获和用户提示

## 文件结构
```
├── index.html                    # 主页面，包含PDF下载区域
├── js/pdf-download.js           # PDF下载功能JavaScript
├── css/styles.css               # 包含PDF下载模块样式
├── js/translations.js           # 多语言翻译文件
└── assets/Shenbai_24_06_2025.pdf      # PDF文件（需要手动添加）
```

## 使用方法
1. 将实际的PDF文件放置在 `assets/Shenbai_24_06_2025.pdf`
2. 页面加载后会自动初始化下载模块
3. 用户点击下载按钮即可下载PDF文件

## 自定义配置
在 `js/pdf-download.js` 中可以调整以下参数：
- `maxDownloadsPerHour`: 每小时最大下载次数（默认5次）
- `downloadCooldown`: 下载间隔时间（默认60000毫秒）

## 注意事项
- 当前实现为前端限制，如需更严格的保护，建议配合服务器端验证
- PDF文件需要手动添加到assets目录
- 建议定期检查下载统计和用户反馈
